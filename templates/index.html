ℹ️ 关于 NetPulse

NetPulse-Pro 网脉 - 轻量级网络设备管理系统

📌 功能特性：

  • ✅ 自动发现局域网所有设备（ARP扫描 + Ping扫描）
  • ✅ 实时监控每台设备的上下行速率
  • ✅ 精确统计每台设备的流量使用（iptables内核级计数）
  • ✅ 按小时/天/周/月查看历史流量数据
  • ✅ 记录设备连接/断开事件
  • ✅ 设备命名与备注管理
  • ✅ MAC地址厂商自动识别
  • ✅ 🚫 设备封禁（踢出网络，ARP欺骗+iptables DROP）
  • ✅ ⏱️ 设备限速（tc HTB流量控制，可设上下行带宽）
  • ✅ 设备管理状态实时显示
  • ✅ 📊 周期流量统计（每月/每季度/每年/自定义，手动清零）

🔧 技术栈：Python Flask + SQLite + iptables + tc + ARP欺骗 + Chart.js

💾 数据存储：本地SQLite数据库，数据保留90天

⚠️ 注意：设备封禁和限速功能通过ARP欺骗实现，需要设备与Orange Pi在同一局域网。封禁/限速可能对部分有ARP防护的设备无效。
