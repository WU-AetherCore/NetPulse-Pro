# 24 小时运行与 SD 卡减写

实时速率仍按采样周期更新，保存在内存。累计流量、排行和小时/日期统计默认每 60 秒批量提交 SQLite；正常停止服务时保存剩余统计。事务失败保留待写数据，下一周期重试。周期重置前先保存上一周期的数据。

`NETPULSE_TRAFFIC_FLUSH_SECONDS=60` 可调整提交周期，最低 10 秒。意外断电或强制结束可能丢失尚未提交的统计，默认最多约 60 秒；磁盘故障导致提交失败时未保存时间会延长。设备上线和配置修改仍正常保存，重复在线观察的时间更新间隔为 30 秒。

部署服务将 Python 字节码放到 `/run/netpulse-pycache`，重启后重新生成。成功的 API GET 轮询不记录访问日志，失败请求和设置变更仍保留。保持 SQLite WAL 和现有 RAM 日志、RAM 交换配置；不要把所有数据库迁入易失内存，也不要关闭文件系统日志来换取寿命。

USB SSD 是通过 USB 接口连接的固态硬盘。以后可把数据库、日志或系统迁到 SSD；没有备用存储时先保存异机备份，减少写入。持续的 MMC 读错误不能靠这些修改修好，仍应更换系统卡并离线检查。不要在已挂载的根分区上执行修复型 fsck。
