# Web 界面与使用说明

## 仪表盘

进入页面首先显示在线设备数、当前上传/下载、累计流量和管理中的设备。点击总流量可设置每月、季度、年度或自定义周期。

实时曲线展示最近 60 个浏览器采样点，刷新会清空这段浏览器内存历史；后台采样约 3 秒一次，不能把图形平滑插值视为逐毫秒测量。历史数据库和实时曲线是两种数据。

仪表盘 TOP 10 只显示在线设备，先按当前速率再按累计流量排序。需要查看离线设备的历史流量，请进入“流量排行”或设备详情。

保留的“全局流量监控”开关属于旧版 ARP/NDP 实验功能。使用开发板网关或板载热点时无需开启它。

## 设备列表

显示名称、IP、MAC、在线状态及流量。可以搜索设备、筛选在线/离线、手动改名、查看详情和标记无线频段。

- 无线频段标签可手工设置，并非总能自动识别。
- 手机使用随机 MAC 时可能被识别为新的设备。
- 小米处于 NAT 路由模式时只显示小米 WAN 的合计，不会穿透 NAT 枚举每个手机。
- 板载热点和有线下游的邻居都会被读取，不再只扫描 `wlan0`。
- 邻居缓存可能滞后；在线状态不是精确的 Wi‑Fi 关联列表。

## 流量排行与周期统计

在“流量排行”选择时间范围，按总量、上传或下载排序；点击某设备查看历史。周期设置可以切换统计跨度。执行清零前确认范围，备份数据库后再做重要统计调整。

累计流量不是每秒速率；MB/s 与 Mbps 相差约 8 倍。内核统计含 IP 数据包开销，与视频播放器有效载荷或运营商账单不会完全一致。

## 网络与热点：USB 上网

1. 查看卡片中的当前 SSID、USB 网卡、IP 和默认网关。
2. 在下拉框选择 USB 无线网卡。
3. 点击“扫描附近 Wi‑Fi”，查看网络名称、信号强度和加密类型。
4. 点击目标网络，或手动填写 Wi‑Fi 名称。
5. 输入密码，点击“连接并保存”，确认短暂断网提示。
6. 等待完成并刷新状态，核实连接及默认路由。

当前表单要求密码，主要支持常见 WPA/WPA2 家用网络；不提供企业 802.1X 配置向导。更换到不同子网时，上游应使用 DHCP。接口下拉框不代表能无条件将任何网卡作为出口，实际 NAT 出口由路由配置文件决定。

板载 `wlan0` 专用于热点，不在上游选择中显示。更换 USB 网卡后，请同步修改两处 `NETPULSE_UPLINK`，详见部署教程。

## 网络与热点：热点配置

可设置：

| 设置 | 规则 |
|---|---|
| 热点名称 | 1–32 UTF‑8 字节，中文占多个字节，不允许控制字符 |
| 新密码 | 8–63 位可打印 ASCII 字符；留空保留现有密码 |
| 信道 | 2.4GHz 的 1、6、11 |
| 安全模式 | 固定 WPA2-PSK / CCMP，沿用已验证兼容配置 |

点击“保存热点设置”后约 2 秒重启热点。修改名称后需要选择新名称，修改密码后可能需要在手机中“忘记网络”再重新连接。

服务启动检查失败会恢复原配置；服务能启动但个别手机不兼容时，仍需通过有线或其他管理通道处理。界面不会回显原密码。

热点是常驻模式，不是仅在上游断线时自动开启。上游断网时热点可以继续提供本地管理，但不能凭空提供互联网。

## 有线网络与热点地址分配

有线卡片显示 `eth0` 状态和网关地址。DHCP 卡片列出热点租约；一个租约可持续 12 小时，因此租约存在不说明设备正在在线。

路由器保留自己的 DHCP 时，应使用 WAN 接开发板。将两个 DHCP 服务器放在同一二层网络会导致客户端获得错误网关。

## 设备封禁、限速与优先级

这些是从 NetPulse 保留的功能，依赖流量经过开发板及规则所在接口。请先用非关键设备验证。

- 当前限速实现以 `eth0` 的 HTB 为主，将上下行输入取较大值作为类速率；不能宣称对所有拓扑和板载热点实现独立双向限速。
- QoS 优先级是拥塞调度，不是把外网带宽提升到网口标称速率。
- 旧版 ARP/NDP 控制逻辑存在固定网段假设，不建议在 Pro 推荐拓扑中开启全局劫持。

## 浏览记录与 AdGuard Home

AdGuard Home 是外部可选服务，默认访问本机 `http://127.0.0.1:3000` 的 API。需单独安装，并让客户端使用它提供的 DNS。

当前集成没有完整的 AdGuard 登录配置界面；受认证保护的 AdGuard API 可能返回错误。不要为了显示统计而把 AdGuard 管理界面暴露到公网或关闭认证。

浏览记录是 DNS 域名查询记录，不是网页内容、聊天记录或完整 URL。缓存、加密 DNS 和其他 DNS 服务器都会导致记录缺失。默认 DHCP 模板使用外部 DNS，因此不自动产生 AdGuard 浏览记录。

## 网络测速

历史内置测速工具保留自旧版，用镜像下载及 speedtest-cli 测量，受服务器、路由和接口选择影响。上传失败时旧逻辑会用下载的 30% 估算上传；**该值不应被视为实测上传能力**。准确的局域网吞吐验证建议使用两端 `iperf3`，不要以仪表盘当前业务流量代替带宽测试。

## 连接记录

记录设备上线、下线和管理事件。设备扫描有时间间隔，记录时间可能晚于真实接入时间。系统时钟错误会影响历史图和周期统计，部署后应确认时间同步正常。
